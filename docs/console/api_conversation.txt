エンドポイント
--------------

POST {BASE_URL}/api/conversation

認証
----

Authorization: Bearer <TOKEN>

リクエストボディ
----------------

{
  "text": "こんにちは",
  "images": ["data:image/png;base64,..."],
  "interaction_context": {
    "interaction_ref": "interaction:console:direct-123",
    "speaker_ref": "person:external-123",
    "participants": [
      {
        "person_ref": "person:external-123",
        "display_name": "田中"
      }
    ]
  },
  "client_context": {
    "source": "CocoroConsole",
    "client_id": "console-...",
    "active_app": "Slack",
    "window_title": "general | Slack",
    "locale": "ja-JP"
  }
}

images は任意の画像 Data URI 配列である。指定時は最大 1 件にする。
interaction_context は必須であり、初期実装の participants は1件にする。
人物識別は connector 側で完了させ、person_ref は person: で始まる安定参照にする。
participants[].display_name は必須の非空表示名とし、人物同一性には使用しない。
client_context は任意の object である。
標準の client_context は source、client_id、active_app、window_title、locale を含める。

レスポンス例
------------

{
  "ok": true,
  "data": {
    "cycle_id": "cycle:...",
    "interaction_ref": "interaction:console:direct-123",
    "recipient_person_refs": ["person:external-123"],
    "result_kind": "speech",
    "speech": {
      "text": "こんにちは"
    },
    "capability_request": null,
    "autonomous_run": null
  }
}

result_kind は speech、capability_request、noop、internal_failure のいずれかである。
発話がない結果では speech は null になる。

cURLの例
--------

curl.exe -k -X POST {BASE_URL}/api/conversation ^
  -H "Authorization: Bearer <TOKEN>" ^
  -H "Content-Type: application/json" ^
  -d "{\"text\":\"こんにちは\",\"interaction_context\":{\"interaction_ref\":\"interaction:console:direct-123\",\"speaker_ref\":\"person:external-123\",\"participants\":[{\"person_ref\":\"person:external-123\",\"display_name\":\"田中\"}]},\"client_context\":{\"source\":\"CocoroConsole\",\"client_id\":\"console-...\",\"locale\":\"ja-JP\"}}"

PowerShellの例
--------------

Invoke-RestMethod -Method Post `
  -Uri "{BASE_URL}/api/conversation" `
  -Headers @{ Authorization = "Bearer <TOKEN>" } `
  -ContentType "application/json; charset=utf-8" `
  -Body '{"text":"こんにちは","interaction_context":{"interaction_ref":"interaction:console:direct-123","speaker_ref":"person:external-123","participants":[{"person_ref":"person:external-123","display_name":"田中"}]},"client_context":{"source":"CocoroConsole","client_id":"console-...","locale":"ja-JP"}}'
