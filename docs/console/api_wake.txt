エンドポイント
--------------

POST {BASE_URL}/api/wake

認証
----

Authorization: Bearer <TOKEN>

リクエストボディ
----------------

{
  "interaction_context": {
    "interaction_ref": "interaction:console:direct-123",
    "participants": [
      {
        "person_ref": "person:external-123",
        "display_name": "田中"
      }
    ]
  },
  "client_context": {
    "source": "CocoroConsole",
    "client_id": "console-...",
    "active_app": "Slack",
    "window_title": "general | Slack",
    "locale": "ja-JP"
  },
  "reference": {
    "uri": "/tmp/otomekairo-watch/camera/latest.jpg",
    "label": "部屋カメラの変化",
    "reason_summary": "軽量CVが前回との差分を検出した。",
    "content_hint": "auto"
  }
}

client_context は任意の object である。
source、active_app、window_title、locale は起床入力の整形に使われる。
interaction_context は任意であり、対象人物と会話が確定している場合に指定する。
interaction_context を指定する場合、participants[].display_name は必須の非空表示名とし、人物同一性には使用しない。
wake の speaker_ref は省略する。
reference は省略できる。
reference.uri はローカルパス、file:// URL、http:// URL、https:// URL を受け付ける。
reference.content_hint は auto、image、text のいずれかである。省略時は auto とする。
reference の画像は PNG、JPEG、GIF、WebP を受け付け、visual observation として判断へ渡す。
reference のテキストはその wake サイクルの判断入力へ一時的に渡し、raw text は cycle trace の client_context へ保存しない。
API起床は自律判断の機会を与える。必ず発話する命令ではない。
API起床は wake_policy.mode と wake_policy.interval_seconds による間隔判定を使わず即時に実行する。

レスポンス例
------------

{
  "ok": true,
  "data": {
    "cycle_id": "cycle:...",
    "interaction_ref": "interaction:console:direct-123",
    "recipient_person_refs": ["person:external-123"],
    "result_kind": "noop",
    "speech": null,
    "capability_request": null,
    "autonomous_run": null
  }
}

result_kind は speech、capability_request、noop、internal_failure のいずれかである。
外向き発話がない wake では result_kind は noop になり、speech は null になる。

主な失敗
--------

400 invalid_interaction_context: interaction_context の形式が不正である。
400 invalid_interaction_participants: participants または人物参照が不正である。
400 invalid_person_display_name: participants[].display_name が無い、空、または文字列ではない。
400 unsupported_group_interaction: participants が1件ではない。
400 invalid_wake_reference: reference の形式が不正である。
413 wake_reference_too_large: reference の取得結果が大きすぎる。
415 unsupported_wake_reference_content: reference の内容が画像または UTF-8 テキストとして扱えない。
502 wake_reference_unavailable: reference.uri を読み取れない。

cURLの例
--------

curl.exe -k -X POST {BASE_URL}/api/wake ^
  -H "Authorization: Bearer <TOKEN>" ^
  -H "Content-Type: application/json" ^
  -d "{\"interaction_context\":{\"interaction_ref\":\"interaction:console:direct-123\",\"participants\":[{\"person_ref\":\"person:external-123\",\"display_name\":\"田中\"}]},\"client_context\":{\"source\":\"CocoroConsole\",\"client_id\":\"console-...\",\"locale\":\"ja-JP\"},\"reference\":{\"uri\":\"/tmp/otomekairo-watch/camera/latest.jpg\",\"label\":\"部屋カメラの変化\",\"reason_summary\":\"軽量CVが前回との差分を検出した。\",\"content_hint\":\"auto\"}}"

PowerShellの例
--------------

Invoke-RestMethod -Method Post `
  -Uri "{BASE_URL}/api/wake" `
  -Headers @{ Authorization = "Bearer <TOKEN>" } `
  -ContentType "application/json; charset=utf-8" `
  -Body '{"interaction_context":{"interaction_ref":"interaction:console:direct-123","participants":[{"person_ref":"person:external-123","display_name":"田中"}]},"client_context":{"source":"CocoroConsole","client_id":"console-...","locale":"ja-JP"},"reference":{"uri":"/tmp/otomekairo-watch/camera/latest.jpg","label":"部屋カメラの変化","reason_summary":"軽量CVが前回との差分を検出した。","content_hint":"auto"}}'
