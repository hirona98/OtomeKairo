API起床
======

概要
----

POST /api/wake は、OtomeKairo に「いま自律判断してよい」という機会を与える API である。
会話文を送る API ではない。必ず発話させる命令でもない。

- 呼んだ時点で即時に wake 1 サイクルを実行する
- 定期思考（wake_policy）の間隔判定は使わない
- 定期思考の思考前観測（wake_policy.observations）は実行しない
- 判断の結果、発話する場合もあれば、何もしない（noop）場合もある

エンドポイント
--------------

POST {BASE_URL}/api/wake

認証
----

Authorization: Bearer <TOKEN>

リクエスト
----------

リクエスト body のフィールドはすべて任意である。空の object {} でも呼べる。

client_context（任意）
  呼び出し元の短い状況。source、client_id、active_app、window_title、locale などを置ける。
  source、active_app、window_title、locale は起床入力の整形に使う。

interaction_context（任意）
  対象人物と会話が確定しているときだけ付ける。
  付ける場合、interaction_ref と participants が必要である。
  participants[].display_name は敬称を含む完成済みの非空呼び名とする。
  server は display_name を変更せずに使う。人物同一性や配送先は person_ref で確定する。
  wake では speaker_ref は省略する。

reference（任意）
  外部監視などが判断材料として渡す参照である。
  uri はローカルパス、file://、http://、https:// を受け付ける。
  label は参照の短い名前。reason_summary は wake した理由の短い要約。
  content_hint は auto / image / text。省略時は auto。
  画像（PNG / JPEG / GIF / WebP）は visual observation として判断へ渡す。
  テキストは当該サイクルの判断入力へ一時的に渡す。画像本体や raw text を wake body に埋め込まない。

サンプル1: 簡易起床
------------------

「いま一度判断してほしい」だけを伝える。手動実行や Console からの起床に使う。

{
  "client_context": {
    "source": "CocoroConsole",
    "client_id": "console-...",
    "active_app": "Slack",
    "window_title": "general | Slack",
    "locale": "ja-JP"
  }
}

cURL:

curl.exe -k -X POST {BASE_URL}/api/wake ^
  -H "Authorization: Bearer <TOKEN>" ^
  -H "Content-Type: application/json" ^
  -d "{\"client_context\":{\"source\":\"CocoroConsole\",\"client_id\":\"console-...\",\"locale\":\"ja-JP\"}}"

PowerShell:

Invoke-RestMethod -Method Post `
  -Uri "{BASE_URL}/api/wake" `
  -Headers @{ Authorization = "Bearer <TOKEN>" } `
  -ContentType "application/json; charset=utf-8" `
  -Body '{"client_context":{"source":"CocoroConsole","client_id":"console-...","locale":"ja-JP"}}'

サンプル2: 参照付き起床
----------------------

外部監視（watcher など）が変化を検知し、画像やテキストの参照を判断材料として渡すときに使う。
snapshot 本体は body に埋め込まず、uri で渡す。

{
  "client_context": {
    "source": "tapo_c220_watcher",
    "client_id": "watcher-C220",
    "locale": "ja-JP"
  },
  "reference": {
    "uri": "/tmp/otomekairo-watch/camera/latest.jpg",
    "label": "部屋カメラの変化",
    "reason_summary": "軽量CVが前回との差分を検出した。",
    "content_hint": "image"
  }
}

cURL:

curl.exe -k -X POST {BASE_URL}/api/wake ^
  -H "Authorization: Bearer <TOKEN>" ^
  -H "Content-Type: application/json" ^
  -d "{\"client_context\":{\"source\":\"tapo_c220_watcher\",\"client_id\":\"watcher-C220\",\"locale\":\"ja-JP\"},\"reference\":{\"uri\":\"/tmp/otomekairo-watch/camera/latest.jpg\",\"label\":\"部屋カメラの変化\",\"reason_summary\":\"軽量CVが前回との差分を検出した。\",\"content_hint\":\"image\"}}"

PowerShell:

Invoke-RestMethod -Method Post `
  -Uri "{BASE_URL}/api/wake" `
  -Headers @{ Authorization = "Bearer <TOKEN>" } `
  -ContentType "application/json; charset=utf-8" `
  -Body '{"client_context":{"source":"tapo_c220_watcher","client_id":"watcher-C220","locale":"ja-JP"},"reference":{"uri":"/tmp/otomekairo-watch/camera/latest.jpg","label":"部屋カメラの変化","reason_summary":"軽量CVが前回との差分を検出した。","content_hint":"image"}}'

対象人物が決まっているとき
--------------------------

interaction_context を付けると、応答と非同期処理がその interaction_ref / participants を引き継ぐ。
サンプル1・2のいずれにも追加できる。

{
  "interaction_context": {
    "interaction_ref": "interaction:console:direct-123",
    "participants": [
      {
        "person_ref": "person:external-123",
        "display_name": "田中さん"
      }
    ]
  },
  "client_context": {
    "source": "CocoroConsole",
    "client_id": "console-...",
    "locale": "ja-JP"
  }
}

レスポンス例
------------

{
  "ok": true,
  "data": {
    "cycle_id": "cycle:...",
    "interaction_ref": "interaction:console:direct-123",
    "recipient_person_refs": ["person:external-123"],
    "result_kind": "noop",
    "speech": null,
    "capability_request": null,
    "autonomous_run": null
  }
}

result_kind は speech、capability_request、noop、internal_failure のいずれかである。
外向き発話がない wake では result_kind は noop になり、speech は null になる。
発話しなくても API 呼び出し自体は成功しうる。

主な失敗
--------

400 invalid_interaction_context: interaction_context の形式が不正である。
400 invalid_interaction_participants: participants または人物参照が不正である。
400 invalid_person_display_name: participants[].display_name が無い、空、または文字列ではない。
400 unsupported_group_interaction: participants が1件ではない。
400 invalid_wake_reference: reference の形式が不正である。
413 wake_reference_too_large: reference の取得結果が大きすぎる。
415 unsupported_wake_reference_content: reference の内容が画像または UTF-8 テキストとして扱えない。
502 wake_reference_unavailable: reference.uri を読み取れない。
