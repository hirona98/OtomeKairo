# 判断根拠審査

`decision_grounding_review` は `wake / background_thinking` の `outward_speech` 比較結果について、判断理由、前景選択の説明、対象別 stance の理由を一次根拠と照合する LLM 補助処理である。意味境界は [プロンプト文脈分離方針](プロンプト文脈分離方針.md#意味レイヤー) を正とする。

入力は `persona_context`、`person_utterances`、`communication_history`、`workspace_context`、`ongoing_action_summary`、`autonomous_run_summaries`、`candidate_decision`。人物本人の明示の根拠は、会話の `role=user` の発話だけから作る `person_utterances` とする。現在の個の発話や観測・推定を本人の申告へ移さない。`communication_history` は `recent_turns / recent_interactions` を場の境界ごと保持し、返答の実行や反復の根拠として渡す。assistant の発話の存在と、その発話に含まれる人物状態の推測は別に扱う。自律実行の完了は `autonomous_run_summaries` で確認する。

出力は `outcome=allow|reconsider` と `reason_summary` の2キーを持つ JSON object。`reconsider` の場合は同じ判断文脈と審査理由で1回再判断し、再度審査する。再判断の理由も根拠に合わない場合は明示失敗とする。契約違反の repair は共通 transport の規則に従う。
