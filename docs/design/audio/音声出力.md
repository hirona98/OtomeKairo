# 音声出力

## 正本境界

この文書は、合成済み assistant 音声の出力先選択と配送の意味規則を正本にする。設定と API wire は [../api/状態と設定.md](../api/状態と設定.md)、event wire は [../api/event_stream.md](../api/event_stream.md) を正とする。

## 出力先

`audio_output_settings.destination` は次の1件を明示的に保存する。初期値は `otomekairo` とする。

| 値 | 配送する `client_kind` | 再生主体 |
| --- | --- | --- |
| `otomekairo` | `otomekairo_audio` | Ubuntu microphone connector の出力機能 |
| `cocoro_console` | `cocoro_console` | 起動中の CocoroConsole |
| `browser` | `browser` | 起動中のブラウザ UI |

server は1発話につき1回だけ音声合成し、選択された種類で `assistant_audio` を購読する起動中の全 client へ、同じ metadata と WAV binary を配送する。入力元、会話を送信した client、接続順、購読 client が1件だけであることを出力先の決定に使用しない。

保存先が `cocoro_console` で、発話受付時に `assistant_audio` を購読する CocoroConsole が0件の場合、その発話の配送先を `otomekairo` とする。受付後は配送先を変更しない。その他の保存先では別種類へ切り替えない。確定した配送先の購読 client が0件なら `tts_target_unavailable` とする。

## OtomeKairo ローカル出力

`destination=otomekairo` では `audio_output_settings.local_output_device` の `host_api / name` を物理デバイス識別子として完全一致させる。値は明示設定し、OS既定デバイス、同名候補、別デバイスへ補完しない。

microphone connector は入力デバイスと出力デバイスの catalog を報告する。保存先が `otomekairo` または `cocoro_console` で、保存済み出力デバイスが一意に存在する間だけ `client_kind=otomekairo_audio` で event stream に接続する。`cocoro_console` 選択中の接続は、CocoroConsole 未接続時の出力先として待機する。WAV は PCM 16-bit または IEEE float 32-bit の sample rate / channel 数をそのまま指定デバイスへ再生し、変換や downmix を行わない。

## 表示との独立

`conversation_input` と `assistant_message` のチャット同期は音声出力先から独立する。`tts.enabled=false` または音声配送失敗でも発話本文の表示は取り消さない。
